# CS-320-Module-Eight-Journal

How can I ensure that my code, program, or software is functional and secure?
I ensure that the software is functional and secure by constant testing, automated quality checks, and adherence to secure coding standards to catch vulnerabilities early.

How do I interpret user needs and incorporate them into a program?
Interpreting user needs involves gathering clear requirements, writing user focused stories, and building early prototypes to test assumptions before deep development begins.

How do I approach designing software? 
Approaching software design means planning a scalable system architecture, applying principles like SOLID, and breaking programs into maintainable components.
